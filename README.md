# Linkx

Linkx es una aplicación web inspirada en Linktree que permite centralizar todos tus enlaces importantes en una sola página, ofreciendo una experiencia sencilla, rápida y totalmente personalizable.

### ✨ Características
- Gestión de enlaces personalizados.
- Diseño moderno y responsive.
- Página única para compartir redes sociales y proyectos.
- Interfaz intuitiva y fácil de usar.
- Optimizada para dispositivos móviles.

### 🚀 Objetivo
Facilitar la creación de una página personal donde los usuarios puedan reunir y compartir todo su contenido digital desde una única URL.
